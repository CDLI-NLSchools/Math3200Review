# Math 3200 Review

A practice question bank for Advanced Mathematics 3200 (Newfoundland and Labrador), built on the same single-file app chassis as the Math 2201 and Math 3201 review apps.

Open the app, choose units or specific curriculum indicators, set how many questions and the level mix you want, and practise. Questions are generated fresh on every draw, worked solutions use centred aligned steps, and a printable practice sheet with an answer key can be generated from any set.

- Mid-course review preset: Units 1 to 5, using the published PEP mid-course blueprint mix (about 20% Level 1, 62% Level 2, 18% Level 3).
- Final review preset: Units 6 to 9. The end-of-course blueprint is not yet published; the preset uses 20 / 60 / 20 as an interim calibration.
- Multiple choice options follow the provincial item-writing guide: numeric options in ascending order, other options in alphabetical order.
- No graphing calculators are permitted on the PEP exams, so every question is solvable by hand.

Status: draft. The bank is being built unit by unit and the app stays in draft until it passes QA.
